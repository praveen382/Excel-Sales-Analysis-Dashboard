# Excel Sales Analysis Dashboard

## Project Overview
This project analyzes sales performance across different regions and product categories using Microsoft Excel.

## Objectives
- Clean and preprocess sales data
- Analyze regional sales performance
- Identify top-performing categories
- Measure profit and discount impact
- Create interactive dashboard

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Slicers
- Dashboard Design

## Key Metrics
- Total Sales
- Total Profit
- Highest Selling Category
- Average Profit Margin

## Dashboard Features
- Region-wise Sales Analysis
- Category-wise Profit Analysis
- Interactive Slicers
- KPI Cards

## Key Insights
- Identified top-performing regions
- Analyzed category profitability
- Evaluated discount impact on profit
- Generated business recommendations
